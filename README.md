# 帅照合成大作战

合成大西瓜风格的照片合成物理小游戏。

## 项目结构

```
ugly-merge/
├── index.html          # 主页面
├── css/
│   └── style.css       # 样式文件
├── js/
│   └── game.js         # 游戏逻辑
├── lib/
│   └── matter.min.js   # 物理引擎（本地，离线可用）
├── assets/
│   └── images/         # 所有图片素材
│       ├── ma1-7.jpg       # 老马展示图
│       ├── pang1-7.jpg     # 老胖展示图
│       ├── ji1-7.jpg       # 鸡展示图
│       ├── dl_ma1-7.jpg    # 老马下载图
│       ├── dl_pang1-7.jpg  # 老胖下载图
│       └── dl_ji1-7.jpeg   # 鸡下载图
├── CNAME             # 自定义域名配置
└── README.md
```

## 离线运行

直接用浏览器打开 `index.html` 即可，无需网络。所有依赖（matter-js）和图片均已本地化。

## 游戏玩法

- 拖拽小球到指定位置松手落下
- 两颗同等级小球相撞合成更大新球
- 合成等级7终极照片即游戏胜利
- 4个关卡：老马、老胖、混合挑战、鸡
- 图鉴系统：游戏中合成对应等级后解锁图鉴
- 图鉴支持图片预览和下载

## 开发说明

- 物理引擎：matter-js 0.20.0
- 纯前端实现，无后端依赖
- 修改 `js/game.js` 调整游戏逻辑
- 修改 `css/style.css` 调整样式
